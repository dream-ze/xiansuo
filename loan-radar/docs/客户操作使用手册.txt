1. 系统简介
================================================================================

智获客 · 助贷线索雷达是一款面向助贷行业的一体化获客系统，集成了"线索雷达"
和"小红书运营"两大核心模块，帮助助贷从业者从社交媒体发现潜在客户并自动运营
内容。

【线索雷达核心流程】

  配置监控源 → 发起采集 → 帖子池/评论池 → 线索识别与分级 → 线索池
  → CRM 跟进 → 每日获客报告

通过配置关键词、同行账号等监控源，系统自动从社交平台（小红书、抖音、知乎）
采集内容，识别潜在贷款需求线索，按 A/B/C/D 四级评分，支持线索转 CRM 跟进
和每日报告输出。

【小红书运营核心流程】

  账号矩阵管理 → 笔记发现/收藏 → AI 内容改写/生成 → 图片/视频工坊
  → 草稿工坊 → 发布中心 → 数据洞察

管理多个小红书账号，发现优质笔记内容，借助 AI 改写生成原创草稿，通过图片/
视频工坊制作素材，在发布中心统一发布，并查看数据洞察分析运营效果。

【一体化联动】

线索雷达采集到的优质帖子可收藏到内容库，作为小红书运营的素材来源，实现
"采集 → 灵感 → 创作 → 发布"的完整闭环。

【AI 智能工作流】

V3.0 新增 AI 智能工作流引擎，将线索识别、话术生成、合规审核等环节自动化
串联，实现"AI 处理 + 人工审核"的混合工作模式：

  线索评分工作流：规则预筛选 → AI 精准识别 → 自动落库
  话术生成工作流：RAG 知识检索 → AI 话术生成 → 合规检查 → 风险门控 → 人工审核
  内容发布工作流：质量评估 → 合规检查 → 风险门控 → 人工审核

核心特性：
  - 结构化输出：AI 返回结构化 JSON，确保数据可落库、可展示、可审核
  - 合规双保险：关键词检测 + AI 语义审核双重合规把关
  - 风险分级：低风险自动通过，高风险必须人工确认
  - RAG 增强：素材库、平台规则、历史优质话术参与 AI 生成
  - 全程可追溯：每次工作流执行均有完整日志和状态记录

3. 安装与启动
================================================================================

3.1 安装程序版（推荐）
─────────────────────

  1) 双击安装包"助贷线索雷达 Setup 1.0.0.exe"。
  2) 如出现 Windows 安全提示，点击"更多信息" → "仍要运行"。
  3) 按安装向导完成安装。
  4) 安装完成后，双击桌面图标"智获客雷达"启动。

3.2 首次启动说明
─────────────────

  首次启动会自动初始化数据库与服务，通常耗时 30-60 秒。

  【注意】请在首次启动时保持窗口打开，不要中途关闭。

3.3 启动成功标志
─────────────────

  - 页面可正常打开登录界面
  - 登录后左侧导航栏显示完整菜单（线索雷达 + 小红书运营 + 通用功能）

================================================================================
4. 账号登录
================================================================================

  1) 打开系统后进入登录页。
  2) 输入管理员分配的账号和密码。
  3) 点击"登录"，成功后进入工作台。

  【提示】首次使用可点击登录页的"注册"创建测试账号，或由管理员统一下发账号。

6. 线索雷达模块
================================================================================

6.1 工作台
──────────

工作台是系统的首页，提供全局数据概览。

主要功能：
  - 数据统计卡片：展示今日/昨日的帖子数、评论数、线索数、A级线索数等关键指标
  - CRM 跟进提醒：显示已逾期、今日待跟进、明日待跟进的客户数量
  - 采集引擎状态：显示 MediaCrawler 采集引擎是否在线
  - 数据趋势图：展示近期的线索和采集趋势

操作建议：每日登录后首先查看工作台，了解整体获客状态和待办事项。

──────────

6.2 采集中心
──────────

采集中心包含"监控源管理"和"采集任务"两个 Tab 页。

6.2.1 监控源管理
────────────────

监控源是采集的起点，支持四种类型：

  监控源类型    说明                    示例
  ──────────    ────                    ────
  关键词        按关键词搜索采集        "征信花了"、"贷款利率"
  同行账号      采集指定账号发布的内容  某贷款博主的小红书主页
  指定帖子      采集指定帖子及其评论    某篇小红书帖子的链接
  热门规则      按热门规则采集          平台热门话题相关内容

创建监控源步骤：

  1) 点击"新增监控源"按钮
  2) 填写配置信息：
     - 监控源类型：选择关键词/同行账号/指定帖子/热门规则
     - 平台：选择小红书/抖音/知乎
     - 采集值：输入关键词、账号ID或帖子链接
     - 时间范围（可选）：选择 7天/15天/30天/90天，仅入库该时间范围内的内容
     - 定时调度（可选）：设置 Cron 表达式实现自动定时采集，
       如 "0 */2 * * *" 表示每2小时采集一次
  3) 点击"保存"

立即采集：

  - 在监控源列表中，点击对应行的"立即采集"按钮
  - 系统将创建采集任务并加入队列
  - 可切换到"采集任务"Tab 查看任务状态

6.2.2 采集任务
──────────────

采集任务页面展示所有采集任务的执行情况。

任务状态说明：

  状态      说明
  ────      ────
  排队中    任务已创建，等待执行（同一时间仅执行一个任务）
  运行中    任务正在执行
  成功      采集完成，可查看结果
  失败      采集失败，可查看错误原因并重试

任务详情：

  - 点击任务行的"详情"按钮，打开任务详情弹窗
  - 详情包含：基础信息、采集配置、采集结果统计（帖子数/评论数/线索数/同行数）
  - 失败任务：显示错误详情、原因分析和修复建议，支持一键"重试采集"
  - 成功任务：提供快捷入口跳转到帖子池、评论池、线索池或生成日报

失败类型说明：

  失败类型      处理建议
  ──────────    ──────────────────
  网络超时      检查网络连接后重试
  Cookie 过期   重新登录小红书账号
  平台风控      降低采集频率，稍后重试
  参数错误      检查监控源配置
  服务不可用    检查 MediaCrawler 服务状态

──────────

6.3 帖子池
──────────

帖子池展示所有采集到的帖子内容。

主要功能：
  - 帖子列表：展示帖子标题、来源平台、发布时间、评论数、点赞数等
  - 查看详情：点击帖子可查看完整内容
  - 原帖链接：可跳转到平台原帖查看
  - 收藏到内容库：将优质帖子收藏，作为小红书运营的素材来源
  - 筛选过滤：按平台、时间范围、监控源等条件筛选

【提示】帖子池是线索雷达和小红书运营的连接点——采集到的优质内容可收藏后
用于 AI 改写生成小红书笔记。

──────────

6.4 线索池
──────────

线索池是系统的核心页面，展示所有识别出的潜在客户线索。

线索等级说明：

  等级      含义                          建议操作
  ────      ────                          ────────
  A 级      高意向线索，明确表达贷款需求  优先跟进，尽快联系
  B 级      中等意向，有相关需求迹象      及时跟进，深入了解
  C 级      低意向，需求不明确            适当关注，等待时机
  D 级      无明显意向                    暂不跟进

线索信息说明：

每条线索展示以下信息：
  - 来源平台：小红书/抖音/知乎
  - 来源帖子：可点击跳转查看原帖
  - 评论内容：触发线索的原始评论
  - 命中证据：系统识别到的需求关键词
  - 判断理由：AI 分析的线索评级依据
  - 建议话术：系统生成的跟进沟通建议
  - 跟进状态：当前线索的处理状态
  - 备注：可手动添加的备注信息

V3.0 新增 AI 识别字段：
  - AI 识别标记：该线索是否经过 AI 精准识别
  - AI 置信度：AI 判断该线索为真实需求的置信分数（0-1）
  - AI 需求摘要：AI 对客户需求的精炼概括
  - AI 关键证据：AI 提取的关键需求证据
  - AI 推理过程：AI 的分析推理说明
  - 关联工作流：触发该线索的工作流运行 ID

线索状态流转：

  新线索 → 已跟进 → 有意向 → 已转化
                    → 无效

  - 新线索：尚未联系
  - 已跟进：已首次联系
  - 有意向：客户表示有兴趣
  - 已转化：成功转化为客户
  - 无效：线索无效或客户明确拒绝

线索操作：
  - 修改状态：在线索详情中修改跟进状态
  - 添加备注：记录沟通情况
  - 转入 CRM：将高价值线索转为客户，进入 CRM 跟进台
  - 导出 CSV：批量导出线索数据（含备注列），方便线下处理

评分规则：

线索池页面还包含"评分规则"子页面：
  - 查看和编辑线索评分规则
  - 支持单条测试：输入测试文本，查看评分结果
  - 支持批量测试：批量验证评分效果
  - 热重载：修改规则后立即生效，无需重启

──────────

6.5 CRM 跟进
────────────

CRM 跟进台用于管理已转化的客户，记录沟通历史和设置跟进提醒。

CRM 仪表板：
  - 统计概览：客户总数、各状态客户数
  - 跟进提醒：按时间维度展示待跟进客户
    · 已逾期：超过计划跟进时间的客户
    · 今日跟进：今天需要跟进的客户
    · 明日跟进：明天需要跟进的客户
    · 本周跟进：本周内需要跟进的客户

客户状态（7 种）：

  待跟进 → 已联系 → 有意向 → 已加微信 → 已申请 → 已转化
                                                    → 无效

  状态        说明
  ────        ────
  待跟进      新转入的客户，尚未联系
  已联系      已首次联系
  有意向      客户表示有兴趣
  已加微信    已添加客户微信
  已申请      客户已提交贷款申请
  已转化      贷款申请已通过
  无效        客户无效或明确拒绝

客户来源（两种方式）：

  1) 线索转客户：在线索池中点击"转入 CRM"
  2) 手动录入：在 CRM 页面点击"新增客户"，手动填写客户信息

跟进记录：
  - 选择客户后可添加跟进记录
  - 跟进方式：电话/微信/短信/上门/其他
  - 跟进内容：记录沟通要点
  - 下次跟进时间：设置提醒，避免遗漏

──────────

6.6 同行发现
────────────

系统在采集过程中会自动识别潜在的同行账号，展示在同行发现页面。

操作说明：
  - 通过：确认为同行账号，可加入监控源持续监控其动态
  - 忽略：非同行账号，忽略不再提醒
  - 查看详情：查看账号的基本信息和发布内容

【提示】通过监控同行账号，可以了解竞品的获客策略和内容方向，为自身运营
提供参考。

──────────

6.7 获客报告
────────────

获客报告页面用于生成每日经营报告，适合团队复盘。

生成报告步骤：
  1) 选择平台范围：全平台/小红书/抖音/知乎
  2) 点击"生成今日报告"
  3) 等待报告生成完成

报告内容包含：
  - 扫描概况：今日采集的帖子数、评论数、线索数
  - A级线索 Top 10：当日最高意向的线索详情
  - 典型需求证据：代表性的客户需求原文
  - 建议跟进话术：AI 生成的沟通建议
  - 同行账号发现：新发现的竞品账号
  - 明日采集建议：基于今日数据的优化建议
  - CRM 统计：客户跟进情况汇总
  - 合规提醒：数据使用合规提示

导出方式：
  - 复制摘要：一键复制报告文字内容
  - 导出 Markdown：下载 .md 格式文件，方便分享

7. 小红书运营模块
================================================================================

7.1 运营总览
────────────

小红书运营总览页面展示账号运营的整体数据。

主要展示内容：
  - 账号数量与状态
  - 近期发布笔记数
  - 互动数据概览
  - 运营趋势图表

──────────

7.2 账号矩阵
────────────

账号矩阵用于管理小红书平台账号，支持三种登录方式。

登录方式一：二维码登录

  1) 点击"添加账号"
  2) 选择登录方式为"二维码登录"
  3) 系统生成二维码
  4) 打开小红书 App 扫描二维码
  5) 在手机上确认登录

9. AI 智能工作流模块
================================================================================

9.1 工作流引擎概述
──────────────────

AI 智能工作流引擎是 V3.0 的核心升级，将原本分散的 AI 功能串联为自动化流水线，
实现"AI 处理 + 人工审核"的混合工作模式。

工作流类型：

  工作流名称      节点链路                                              适用场景
  ──────────      ────────                                              ────────
  线索智能评分    规则预筛选 → AI 精准识别 → 线索落库                  对新采集内容进行评分
  AI 话术生成     RAG 检索 → AI 话术生成 → 合规检查 → 风险门控        为线索生成跟进话术
                   → 人工审核（高风险时）
  内容发布审核    质量评估 → 合规检查 → 风险门控 → 人工审核           发布前合规把关
                   （高风险时）

工作流状态说明：

  状态      说明
  ────      ────
  pending   工作流已创建，等待执行
  running   工作流正在执行中
  paused    工作流暂停，等待人工审核
  completed 工作流执行完成
  failed    工作流执行失败，可重试
  cancelled 工作流已取消

核心机制：
  - 节点串联执行：每个节点处理后将结果传递给下一个节点
  - 暂停恢复：高风险内容触发暂停，人工审核后可恢复执行
  - 失败重试：执行失败的工作流可从失败节点重新执行
  - 全程日志：每个节点的输入、输出、耗时、Token 用量均有记录

──────────

9.2 线索智能评分
────────────────

线索智能评分工作流将规则引擎和 AI 识别结合，对采集到的内容进行精准评分。

触发方式：
  - 在帖子池/评论池中选择内容，点击"智能评分"按钮
  - 通过 API 接口批量触发

工作流执行过程：

  第一步：规则预筛选
    - 基于关键词匹配快速计算初步分数
    - 识别需求类型（借款需求、征信咨询、产品比较等）
    - 检测否定词（"不想贷款"、"已经办了"等）
    - 计算初步线索等级（A/B/C/D）

  第二步：AI 精准识别
    - 将文本发送给 AI 模型进行深度分析
    - AI 返回结构化结果：需求类型、置信度、关键证据、推理过程
    - 结合规则分数和 AI 结果综合评定最终等级
    - 如 AI 不可用，自动回退到纯规则评分

  第三步：线索落库
    - 自动创建或更新线索记录
    - 去重检测：避免同一用户重复入库
    - 合并更新：如线索已存在，更新评分和证据

评分结果说明：

  字段          说明
  ────          ────
  rule_score    规则引擎评分（0-100）
  lead_level    最终线索等级（A/B/C/D）
  ai_confidence AI 置信度（0-1，越高越可靠）
  demand_type   需求类型分类
  evidence      命中关键词和证据链
  reason        评级理由

──────────

9.3 AI 话术生成
────────────────

AI 话术生成工作流基于线索信息和知识库，自动生成个性化的跟进话术。

触发方式：
  - 在线索池中选择线索，点击"生成话术"按钮
  - 在线索详情页点击"AI 话术"标签

工作流执行过程：

  第一步：RAG 知识检索
    - 根据线索的需求类型和关键词，从知识库中检索相关素材
    - 检索来源：平台规则、历史优质话术、素材库内容
    - 检索结果作为 AI 生成的上下文参考

  第二步：AI 话术生成
    - 结合线索信息 + RAG 检索结果，调用 AI 生成话术
    - 生成多个候选版本（通常 3 个），各有侧重：
      · 版本 1：专业咨询型（偏正式）
      · 版本 2：亲和关怀型（偏轻松）
      · 版本 3：直接引导型（偏行动）
    - AI 返回结构化结果，包含每个版本的文本和适用场景

  第三步：合规检查
    - 关键词检测：扫描话术中是否包含敏感词（如"包下款"、"零利息"）
    - AI 语义审核：检测隐含的违规表述
    - 标记违规项和修改建议
    - 如发现违规，标记风险等级

  第四步：风险门控
    - 根据合规检查结果判断风险等级
    - 低风险（low）：自动通过，话术可直接使用
    - 中风险（medium）：自动通过，但标记提醒
    - 高风险（high）：暂停工作流，进入人工审核
    - 极高风险（critical）：暂停工作流，必须人工审核

  第五步：人工审核（仅高风险时触发）
    - 话术进入审核队列，等待人工确认
    - 审核人可选择：通过 / 拒绝 / 修改后通过
    - 审核通过后话术正式生效

话术使用：
  - 生成的话术显示在线索详情页
  - 可选择任一候选版本使用
  - 可手动编辑修改后保存

──────────

9.4 内容发布审核
────────────────

内容发布审核工作流在笔记发布前进行质量和合规双重检查，确保发布内容安全合规。

触发方式：
  - 在草稿工坊点击"提交审核"按钮
  - 在发布中心提交发布任务时自动触发

工作流执行过程：

  第一步：质量评估
    - AI 对内容进行多维度质量评分：
      · 相关性：内容与目标受众的匹配度
      · 完整性：信息是否完整充分
      · 可读性：文字表达是否清晰流畅
    - 综合评分 0-1，低于阈值时给出改进建议
    - 如 AI 不可用，使用启发式规则评估

  第二步：合规检查
    - 与话术生成工作流相同的合规检查流程
    - 额外检查：平台特定规则（小红书社区规范等）
    - 检测站外引流信息（微信号、二维码等）

  第三步：风险门控
    - 根据合规结果判定风险等级
    - 低风险内容自动通过，可直接发布
    - 高风险内容暂停，进入人工审核

  第四步：人工审核（仅高风险时触发）
    - 内容进入审核队列
    - 审核人可查看合规违规详情
    - 可选择：通过发布 / 拒绝发布 / 修改内容后通过

审核结果说明：

  结果      说明
  ────      ────
  auto_approved    内容合规，自动通过
  manual_review    需要人工审核
  approved         人工审核通过
  rejected         人工审核拒绝

9.5 合规规则管理
────────────────

合规规则管理页面用于维护系统的合规关键词库和审核规则。

规则分类：

  分类                说明                      示例
  ────                ────                      ────
  platform_rule       平台社区规范              不得承诺包下款
  industry_regulation 金融行业监管规定          不得宣传零利息
  internal_policy     企业内部合规策略          话术中应包含风险提示

规则严重程度：

  级别      说明                          处理方式
  ────      ────                          ────────
  critical  严重违规，可能引发法律风险    必须人工审核
  high      高风险，可能违反平台规则      需要人工审核
  medium    中等风险，需注意              自动通过但标记提醒
  low       低风险，轻微问题              自动通过

操作说明：
  - 查看规则列表：按分类、严重程度筛选
  - 新增规则：填写分类、规则文本、严重程度
  - 编辑规则：修改规则内容或启停状态
  - 删除规则：移除不再需要的规则
  - 初始化默认规则：一键导入系统预设的合规规则

【重要】建议首次使用时点击"初始化默认规则"，导入预设的金融行业合规规则。
预设规则涵盖小红书社区规范、金融营销规范和内部合规策略三大类。

9.6 人工审核队列
────────────────

人工审核队列集中展示所有需要人工确认的高风险内容。

队列入口：

  - 顶部通知铃铛会显示待审核数量

审核列表说明：

  字段          说明
  ────          ────
  内容类型      follow_up_script（话术）/ draft（草稿）
  风险等级      critical / high / medium
  合规结果      违规项详情和修改建议
  状态          pending（待审核）/ approved（已通过）/ rejected（已拒绝）
  提交时间      进入审核队列的时间

审核操作：

  1) 在审核列表中点击待审核条目
  2) 查看内容详情和合规违规项
  3) 选择审核操作：
     - 通过：内容合规，允许使用/发布
     - 拒绝：内容不合规，打回修改
     - 修改后通过：手动修改内容后通过（可编辑内容文本）
  4) 填写审核意见（可选）
  5) 提交审核结果

审核结果处理：
  - 通过：关联的工作流自动恢复执行
  - 拒绝：关联的工作流标记为取消
  - 修改后通过：使用修改后的内容继续执行

【提示】建议每日至少检查一次审核队列，避免高风险内容积压影响业务流程。

──────────

9.7 知识库管理
────────────────

知识库是 RAG（检索增强生成）的基础，为 AI 话术生成提供上下文参考。

知识来源类型：

  来源类型          说明                      索引内容
  ────────          ────                      ────────
  material          素材库（收藏的笔记/帖子）  笔记标题+正文
  platform_rule     平台规则（合规规则）       规则文本
  quality_script    历史优质话术              话术全文

操作说明：

  查看知识库统计：
    - 显示各类型知识的条目数量
    - 查看知识条目列表

  索引素材：
    - 选择来源类型和具体笔记
    - 系统自动生成向量嵌入并入库
    - 支持批量索引：一键索引所有笔记

  搜索知识：
    - 输入查询文本
    - 系统返回最相关的知识条目
    - 可按来源类型过滤
    - 显示相关度评分

  删除知识：
    - 删除不再需要的知识条目
    - 删除后 AI 生成时不再参考该内容

【重要】知识库的质量直接影响 AI 话术生成的效果。建议：
  - 定期将优质话术添加到知识库
  - 保持合规规则的完整和更新
  - 索引与业务相关的优质笔记内容

9.8 工作流运行记录
────────────────

工作流运行记录页面展示所有工作流的执行历史，支持问题排查和效果分析。

记录列表说明：

  字段            说明
  ────            ────
  工作流 ID       唯一标识符
  工作流类型      lead_scoring / script_generation / content_publish
  状态            pending / running / paused / completed / failed / cancelled
  当前节点        正在执行的节点名称
  暂停节点        暂停时所在的节点（如 human_approval）
  失败节点        失败时所在的节点
  错误信息        失败原因描述
  重试次数        已重试的次数
  创建时间        工作流创建时间
  完成时间        工作流完成时间

操作说明：

  查看详情：
    - 点击工作流 ID 查看完整信息
    - 包含输入数据、各节点输出、最终结果

  查看日志：
    - 查看每个节点的执行日志
    - 包含：节点名称、事件类型、输入/输出快照、耗时、Token 用量、费用估算

  恢复执行：
    - 对暂停状态的工作流，审核通过后可恢复
    - 选择"通过"或"拒绝"，填写审核意见

  重试执行：
    - 对失败状态的工作流，可从失败节点重新执行
    - 重试次数会递增记录

筛选过滤：
  - 按工作流类型筛选
  - 按状态筛选
  - 按时间排序

10. 首次使用快速上手（10 分钟）
================================================================================

建议首次使用时按以下顺序操作，快速验证系统功能：

第一步：线索雷达链路（5 分钟）
──────────────────────────────

  1) 进入"采集中心"，新增一个关键词监控源（例如：征信花了），平台选小红书
  2) 点击"立即采集"，切换到采集任务 Tab 查看状态
  3) 采集完成后，进入"帖子池"查看采集到的帖子
  4) 选择一条帖子，点击"智能评分"触发 AI 线索评分工作流
  5) 进入"线索池"，查看 A/B/C/D 分级线索及 AI 识别结果
  6) 选择一条 A 级线索，点击"生成话术"触发 AI 话术生成工作流
  7) 查看生成的话术候选版本，选择合适的版本
  8) 点击"转入 CRM"
  9) 进入"CRM 跟进"，为该客户添加一条跟进记录
  10) 进入"获客报告"，生成今日报告

第二步：小红书运营链路（5 分钟）
──────────────────────────────────

  1) 进入"账号矩阵"，添加一个小红书账号（推荐 Cookie 导入方式最快）
  2) 进入"笔记发现"，搜索关键词浏览笔记，收藏一篇感兴趣的
  3) 进入"内容库"，选择收藏的笔记，点击"AI 改写"
  4) 进入"草稿工坊"，编辑生成的草稿
  5) 点击"提交审核"触发内容发布审核工作流
  6) 如内容为低风险，自动通过；如为高风险，进入人工审核队列
  7) 在"人工审核"页面处理待审核内容（如有）
  8) 审核通过后，点击"发送到发布中心"
  9) 进入"发布中心"，配置发布参数并提交

11. 日常操作 SOP
================================================================================

11.1 每日开始（运营人员）
─────────────────────────

  1) 登录系统，进入"工作台"查看昨日与今日数据概览
  2) 检查"通知中心"，关注 Cookie 过期、任务失败等告警
  3) 进入"采集中心"，确认监控源配置齐全
  4) 执行"立即采集"或等待定时任务自动执行
  5) 检查采集任务状态，处理失败任务

11.2 线索处理（业务人员）
─────────────────────────

  1) 打开"线索池"，按等级优先处理 A 级、B 级线索
  2) 查看证据链与建议话术，判断线索有效性
  3) 对新线索点击"智能评分"触发 AI 线索评分工作流
  4) 查看 AI 识别结果：置信度、需求摘要、关键证据
  5) 对高价值线索点击"生成话术"，获取 AI 生成的跟进话术
  6) 选择合适的话术版本，必要时手动调整
  7) 更新线索状态（新线索 → 已跟进 → 有意向 → 已转化/无效）
  8) 对高价值线索点击"转入 CRM"

11.3 CRM 跟进（销售/顾问）
───────────────────────────

  1) 在"CRM 跟进"页面筛选"今日待跟进"客户
  2) 填写跟进记录（电话/微信/短信/上门/其他）
  3) 设置下次跟进时间，避免漏跟进
  4) 根据沟通进展更新客户状态

11.4 内容运营（运营人员）
─────────────────────────

  1) 进入"笔记发现"，搜索行业关键词，收藏优质笔记
  2) 进入"内容库"，选择笔记进行 AI 改写
  3) 在"草稿工坊"编辑和优化草稿内容
  4) 在"图片工坊/视频工坊"制作素材
  5) 点击"提交审核"触发内容发布审核工作流
  6) 检查"人工审核"队列，处理待审核内容
  7) 审核通过后发送到"发布中心"，配置参数并发布
  8) 在"数据洞察"查看发布效果

11.5 合规管理（合规专员）
─────────────────────────

  1) 进入"合规规则"页面，检查规则是否完整
  2) 首次使用时点击"初始化默认规则"
  3) 根据业务变化新增或修改合规规则
  4) 每日检查"人工审核"队列，处理高风险内容
  5) 审核时关注合规违规详情，确保内容合规
  6) 定期更新知识库，索引新的优质素材和话术

11.6 日报复盘（主管）
─────────────────────

  1) 进入"获客报告"页面生成"今日报告"
  2) 查看 A 级线索 Top、需求关键词分布、同行发现建议
  3) 导出 Markdown 或复制摘要，发送团队群
  4) 根据报告调整监控源配置和采集策略

12. 常见问题处理
================================================================================

12.1 启动失败或白屏
────────────────────

  1) 关闭系统后重新启动
  2) 等待 1-2 分钟完成初始化
  3) 检查是否被杀毒软件拦截，将应用加入白名单
  4) 确认系统满足运行环境要求

12.2 提示端口被占用
────────────────────

  1) 打开任务管理器（Ctrl + Shift + Esc）
  2) 结束残留进程（pythonw.exe、postgres.exe）
  3) 重新启动应用

12.3 采集任务一直失败
──────────────────────

  1) 检查网络连接是否正常
  2) 检查小红书账号登录状态是否过期（Cookie 是否有效）
  3) 在采集任务详情中查看错误原因和失败类型
  4) 按照修复建议处理后点击"重试采集"
  5) 如持续失败，联系技术支持

12.4 AI 功能不可用
───────────────────

  1) 进入"模型配置"页面，确认已配置默认文本模型
  2) 检查 API Key 是否有效
  3) 检查 API 地址是否可访问
  4) 自动运营任务在 AI 不可用时会回退到模板生成

12.5 小红书账号登录失败
────────────────────────

  1) 二维码登录失败：确认二维码未过期，重新生成再扫
  2) 手机验证码登录失败：确认手机号正确，检查验证码是否过期
  3) Cookie 导入失败：确认 Cookie 文本完整复制，未遗漏字段
  4) 登录成功后 Cookie 有有效期，过期后需重新登录

12.6 发布失败
─────────────

  1) 确认使用的是创作者端账号（PC 账号无法发布）
  2) 检查创作者端 Cookie 是否有效
  3) 检查素材（图片/视频）是否上传成功
  4) 查看发布任务的错误信息

12.7 登录异常
─────────────

  1) 确认账号密码是否正确
  2) 让管理员重置密码
  3) 如仍异常，联系技术支持并附截图

12.8 工作流执行失败
───────────────────

  1) 进入"工作流记录"页面，找到失败的工作流
  2) 查看失败节点和错误信息
  3) 常见原因：
     - AI 模型不可用：检查"模型配置"中默认文本模型是否有效
     - API Key 过期：更新模型配置中的 API Key
     - 网络超时：检查网络连接后点击"重试"
  4) 修复问题后点击"重试"重新执行

12.9 人工审核队列一直有内容
───────────────────────────

  1) 检查合规规则是否过于严格（如 medium 级别规则过多）
  2) 适当调整规则的严重程度（将部分 high 降为 medium）
  3) 确认内容是否确实存在合规问题
  4) 及时处理审核队列，避免积压

12.10 AI 话术生成质量不佳
─────────────────────────

  1) 检查知识库是否有足够的参考素材
  2) 进入"知识库"页面，索引更多优质笔记和话术
  3) 检查模型配置是否使用了合适的 AI 模型
  4) 尝试手动编辑 AI 生成的话术，作为优质话术回填知识库

12.11 合规检查误报
──────────────────

  1) 进入"合规规则"页面，检查触发误报的规则
  2) 如规则过于宽泛，修改规则文本使其更精确
  3) 如规则不再适用，可禁用（设为不活跃）或删除
  4) 误报的内容可在人工审核中选择"通过"

14. 使用边界与合规说明
================================================================================

为保障合规使用，系统默认采用"自动生成 + 人工审核"模式：

  [支持] 内容草稿需人工审核后再发布，系统不会自动真实发布
  [支持] Cookie 加密存储，保障账号安全
  [支持] AI 生成的话术经合规检查后，高风险内容必须人工确认
  [支持] 合规规则可自定义，适应不同业务场景
  [支持] 工作流全程可追溯，每个节点有完整日志
  [不支持] 不提供绕过风控、验证码绕过、指纹伪装等能力
  [不支持] 不提供代理池、账号池功能
  [不支持] 平台账号登录态（Cookie）过期后需重新登录
  [不支持] 不自动发布高风险内容，必须经过人工审核

建议角色分工：

  角色            职责
  ────            ────
  运营            监控源配置、采集执行、内容创作与发布
  销售/顾问       线索跟进、客户转化、CRM 管理、话术使用
  合规专员        合规规则维护、人工审核、知识库管理
  主管            日报复盘、策略调整、团队管理

按以上分工执行，可显著提升线索处理效率和内容运营效果。
