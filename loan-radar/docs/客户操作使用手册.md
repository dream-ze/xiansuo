## 1. 系统简介

智获客 · 助贷线索雷达是一款面向助贷行业的一体化获客系统，集成了**线索雷达**和**小红书运营**两大核心模块，帮助助贷从业者从社交媒体发现潜在客户并自动运营内容。

### 线索雷达核心流程

```
配置监控源 → 发起采集 → 帖子池/评论池 → 线索识别与分级 → 线索池 → CRM 跟进 → 每日获客报告
```

通过配置关键词、同行账号等监控源，系统自动从社交平台（小红书、抖音、知乎）采集内容，识别潜在贷款需求线索，按 A/B/C/D 四级评分，支持线索转 CRM 跟进和每日报告输出。

### 小红书运营核心流程

```
账号矩阵管理 → 笔记发现/收藏 → AI 内容改写/生成 → 图片/视频工坊 → 草稿工坊 → 发布中心 → 数据洞察
```

管理多个小红书账号，发现优质笔记内容，借助 AI 改写生成原创草稿，通过图片/视频工坊制作素材，在发布中心统一发布，并查看数据洞察分析运营效果。

### 一体化联动

线索雷达采集到的优质帖子可收藏到内容库，作为小红书运营的素材来源，实现"采集 → 灵感 → 创作 → 发布"的完整闭环。

## 3. 安装与启动

### 3.1 安装程序版（推荐）

1. 双击安装包 `助贷线索雷达 Setup 1.0.0.exe`。
2. 如出现 Windows 安全提示，点击 **"更多信息" → "仍要运行"**。
3. 按安装向导完成安装。
4. 安装完成后，双击桌面图标 **"助获客雷达"** 启动。

### 3.2 首次启动说明

首次启动会自动初始化数据库与服务，通常耗时 **30-60 秒**。

> ⚠️ 请在首次启动时保持窗口打开，不要中途关闭。

### 3.3 启动成功标志

- 页面可正常打开登录界面
- 登录后左侧导航栏显示完整菜单（线索雷达 + 小红书运营 + 通用功能）

## 4. 账号登录

## 6. 线索雷达模块

### 6.1 工作台

工作台是系统的首页，提供全局数据概览。

**主要功能：**

- **数据统计卡片**：展示今日/昨日的帖子数、评论数、线索数、A级线索数等关键指标
- **CRM 跟进提醒**：显示已逾期、今日待跟进、明日待跟进的客户数量
- **采集引擎状态**：显示 MediaCrawler 采集引擎是否在线
- **数据趋势图**：展示近期的线索和采集趋势

**操作建议：** 每日登录后首先查看工作台，了解整体获客状态和待办事项。

---

### 6.2 采集中心

采集中心包含 **监控源管理** 和 **采集任务** 两个 Tab 页。

#### 6.2.1 监控源管理

监控源是采集的起点，支持四种类型：

| 监控源类型 | 说明 | 示例 |
|------------|------|------|
| 关键词 | 按关键词搜索采集 | "征信花了"、"贷款利率" |
| 同行账号 | 采集指定账号发布的内容 | 某贷款博主的小红书主页 |
| 指定帖子 | 采集指定帖子及其评论 | 某篇小红书帖子的链接 |
| 热门规则 | 按热门规则采集 | 平台热门话题相关内容 |

**创建监控源步骤：**

1. 点击 **"新增监控源"** 按钮
2. 填写配置信息：
   - **监控源类型**：选择关键词/同行账号/指定帖子/热门规则
   - **平台**：选择小红书/抖音/知乎
   - **采集值**：输入关键词、账号ID或帖子链接
   - **时间范围**（可选）：选择 7天/15天/30天/90天，仅入库该时间范围内的内容
   - **定时调度**（可选）：设置 Cron 表达式实现自动定时采集，如 `0 */2 * * *` 表示每2小时采集一次
3. 点击 **"保存"**

**立即采集：**

- 在监控源列表中，点击对应行的 **"立即采集"** 按钮
- 系统将创建采集任务并加入队列
- 可切换到 **"采集任务"** Tab 查看任务状态

#### 6.2.2 采集任务

采集任务页面展示所有采集任务的执行情况。

**任务状态说明：**

| 状态 | 说明 |
|------|------|
| 排队中 | 任务已创建，等待执行（同一时间仅执行一个任务） |
| 运行中 | 任务正在执行 |
| 成功 | 采集完成，可查看结果 |
| 失败 | 采集失败，可查看错误原因并重试 |

**任务详情：**

- 点击任务行的 **"详情"** 按钮，打开任务详情弹窗
- 详情包含：基础信息、采集配置、采集结果统计（帖子数/评论数/线索数/同行数）
- 失败任务：显示错误详情、原因分析和修复建议，支持一键 **"重试采集"**
- 成功任务：提供快捷入口跳转到帖子池、评论池、线索池或生成日报

**失败类型说明：**

| 失败类型 | 处理建议 |
|----------|----------|
| 网络超时 | 检查网络连接后重试 |
| Cookie 过期 | 重新登录小红书账号 |
| 平台风控 | 降低采集频率，稍后重试 |
| 参数错误 | 检查监控源配置 |
| 服务不可用 | 检查 MediaCrawler 服务状态 |

### 6.3 帖子池

帖子池展示所有采集到的帖子内容。

**主要功能：**

- **帖子列表**：展示帖子标题、来源平台、发布时间、评论数、点赞数等
- **查看详情**：点击帖子可查看完整内容
- **原帖链接**：可跳转到平台原帖查看
- **收藏到内容库**：将优质帖子收藏，作为小红书运营的素材来源
- **筛选过滤**：按平台、时间范围、监控源等条件筛选

> 💡 帖子池是线索雷达和小红书运营的连接点——采集到的优质内容可收藏后用于 AI 改写生成小红书笔记。

### 6.4 线索池

线索池是系统的核心页面，展示所有识别出的潜在客户线索。

#### 线索等级说明

| 等级 | 含义 | 建议操作 |
|------|------|----------|
| A 级 | 高意向线索，明确表达贷款需求 | 优先跟进，尽快联系 |
| B 级 | 中等意向，有相关需求迹象 | 及时跟进，深入了解 |
| C 级 | 低意向，需求不明确 | 适当关注，等待时机 |
| D 级 | 无明显意向 | 暂不跟进 |

#### 线索信息说明

每条线索展示以下信息：

- **来源平台**：小红书/抖音/知乎
- **来源帖子**：可点击跳转查看原帖
- **评论内容**：触发线索的原始评论
- **命中证据**：系统识别到的需求关键词
- **判断理由**：AI 分析的线索评级依据
- **建议话术**：系统生成的跟进沟通建议
- **跟进状态**：当前线索的处理状态
- **备注**：可手动添加的备注信息

#### 线索状态流转

```
新线索 → 已跟进 → 有意向 → 已转化
                  → 无效
```

- **新线索**：尚未联系
- **已跟进**：已首次联系
- **有意向**：客户表示有兴趣
- **已转化**：成功转化为客户
- **无效**：线索无效或客户明确拒绝

#### 线索操作

- **修改状态**：在线索详情中修改跟进状态
- **添加备注**：记录沟通情况
- **转入 CRM**：将高价值线索转为客户，进入 CRM 跟进台
- **导出 CSV**：批量导出线索数据（含备注列），方便线下处理

#### 评分规则

线索池页面还包含 **评分规则** 子页面：

- 查看和编辑线索评分规则
- 支持单条测试：输入测试文本，查看评分结果
- 支持批量测试：批量验证评分效果
- 热重载：修改规则后立即生效，无需重启

### 6.5 CRM 跟进

CRM 跟进台用于管理已转化的客户，记录沟通历史和设置跟进提醒。

#### CRM 仪表板

- **统计概览**：客户总数、各状态客户数
- **跟进提醒**：按时间维度展示待跟进客户
  - 已逾期：超过计划跟进时间的客户
  - 今日跟进：今天需要跟进的客户
  - 明日跟进：明天需要跟进的客户
  - 本周跟进：本周内需要跟进的客户

#### 客户状态

CRM 支持 7 种客户状态：

```
待跟进 → 已联系 → 有意向 → 已加微信 → 已申请 → 已转化
                                                  → 无效
```

| 状态 | 说明 |
|------|------|
| 待跟进 | 新转入的客户，尚未联系 |
| 已联系 | 已首次联系 |
| 有意向 | 客户表示有兴趣 |
| 已加微信 | 已添加客户微信 |
| 已申请 | 客户已提交贷款申请 |
| 已转化 | 贷款申请已通过 |
| 无效 | 客户无效或明确拒绝 |

#### 客户来源

两种方式将客户录入 CRM：

1. **线索转客户**：在线索池中点击"转入 CRM"
2. **手动录入**：在 CRM 页面点击"新增客户"，手动填写客户信息

#### 跟进记录

- 选择客户后可添加跟进记录
- **跟进方式**：电话/微信/短信/上门/其他
- **跟进内容**：记录沟通要点
- **下次跟进时间**：设置提醒，避免遗漏

### 6.7 获客报告

获客报告页面用于生成每日经营报告，适合团队复盘。

**生成报告步骤：**

**报告内容包含：**

- **合规提醒**：数据使用合规提示

**导出方式：**

- **复制摘要**：一键复制报告文字内容
- **导出 Markdown**：下载 .md 格式文件，方便分享

### 7.2 账号矩阵

账号矩阵用于管理小红书平台账号，支持三种登录方式。

#### 登录方式一：二维码登录

1. 点击 **"添加账号"**
2. 选择登录方式为 **"二维码登录"**
3. 系统生成二维码
4. 打开小红书 App 扫描二维码
5. 在手机上确认登录
6. 系统自动保存账号信息

#### 登录方式二：手机验证码登录

1. 点击 **"添加账号"**
2. 选择登录方式为 **"手机验证码登录"**
3. 输入手机号码
4. 点击 **"发送验证码"**
5. 输入收到的验证码
6. 点击 **"确认登录"**

#### 登录方式三：Cookie 导入

1. 点击 **"添加账号"**
2. 选择登录方式为 **"Cookie 导入"**
3. 在浏览器中登录小红书，复制 Cookie 文本
4. 粘贴到输入框中
5. 点击 **"导入"**，系统自动解析并加密存储

> 💡 **账号类型说明：**
> - **PC 端账号**：用于搜索和采集笔记内容
> - **创作者端账号**：用于发布笔记
> - PC Cookie 可自动同步到创作者端
> - 建议至少配置一个 PC 账号和一个 Creator 账号

#### Cookie 过期处理

- 系统会在 Cookie 即将过期时发送通知
- 收到通知后，按上述方式重新登录即可

## 11. 常见问题处理

### 11.1 启动失败或白屏

1. 关闭系统后重新启动
2. 等待 1-2 分钟完成初始化
3. 检查是否被杀毒软件拦截，将应用加入白名单
4. 确认系统满足运行环境要求

### 11.2 提示端口被占用

1. 打开任务管理器（Ctrl + Shift + Esc）
2. 结束残留进程（pythonw.exe、postgres.exe）
3. 重新启动应用

### 11.3 采集任务一直失败

1. 检查网络连接是否正常
2. 检查小红书账号登录状态是否过期（Cookie 是否有效）
3. 在采集任务详情中查看错误原因和失败类型
4. 按照修复建议处理后点击 **"重试采集"**
5. 如持续失败，联系技术支持

### 11.4 AI 功能不可用

1. 进入 **模型配置** 页面，确认已配置默认文本模型
2. 检查 API Key 是否有效
3. 检查 API 地址是否可访问
4. 自动运营任务在 AI 不可用时会回退到模板生成

### 11.5 小红书账号登录失败

1. **二维码登录失败**：确认二维码未过期，重新生成再扫
2. **手机验证码登录失败**：确认手机号正确，检查验证码是否过期
3. **Cookie 导入失败**：确认 Cookie 文本完整复制，未遗漏字段
4. 登录成功后 Cookie 有有效期，过期后需重新登录

### 11.6 发布失败

1. 确认使用的是创作者端账号（PC 账号无法发布）
2. 检查创作者端 Cookie 是否有效
3. 检查素材（图片/视频）是否上传成功
4. 查看发布任务的错误信息

### 11.7 登录异常

1. 确认账号密码是否正确
2. 让管理员重置密码
3. 如仍异常，联系技术支持并附截图

## 13. 使用边界与合规说明

为保障合规使用，系统默认采用 **"自动生成 + 人工确认"** 模式：

- ✅ 内容草稿需人工审核后再发布，系统不会自动真实发布
- ✅ Cookie 加密存储，保障账号安全
- ❌ 不提供绕过风控、验证码绕过、指纹伪装等能力
- ❌ 不提供代理池、账号池功能
- ❌ 平台账号登录态（Cookie）过期后需重新登录

### 建议角色分工

| 角色 | 职责 |
|------|------|
| 运营 | 监控源配置、采集执行、内容创作与发布 |
| 销售/顾问 | 线索跟进、客户转化、CRM 管理 |
| 主管 | 日报复盘、策略调整、团队管理 |

按以上分工执行，可显著提升线索处理效率和内容运营效果。
