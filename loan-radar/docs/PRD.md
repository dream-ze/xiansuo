# PRD：助贷线索雷达 MVP

## 作用

记录助贷线索雷达 MVP 的产品目标、采集边界、验收标准和后续路线。本文档以当前代码能力为准：MediaCrawler 为唯一可用采集器，支持小红书、抖音、知乎三个平台。

## 当前阶段

当前阶段是"助贷线索雷达 MVP"，面向客户可试用、可交付、愿意付费。

已具备的核心链路：

监控源管理 → 定时采集调度 → 采集任务队列 → MediaCrawler 采集 → 时间范围过滤 → 帖子池 → 评论池 → 线索识别与去重 → 线索池 → 线索转 CRM → 轻 CRM 跟进台 → 今日获客报告 → CSV/Markdown 导出 → 同行账号发现池 → 评分规则管理 → 仪表板

本阶段采集能力：

- **关键词搜索采集**：用户输入关键词，系统通过 MediaCrawler 在指定平台搜索帖子并采集内容和评论。
- **指定帖子采集**：用户输入帖子链接，系统通过 MediaCrawler 采集该帖子的内容和评论。
- **创作者主页采集**：用户输入创作者主页链接，系统通过 MediaCrawler 采集该创作者的帖子。
- **时间范围过滤**：支持 7d/15d/30d/90d 时间范围，设置后自动提升采集量（max_posts 提升至 80），仅入库发布时间在范围内的帖子和评论。
- **定时采集调度**：支持 Cron 表达式配置，自动触发采集任务。
- **采集任务队列**：同一时间仅执行一个采集任务，后续任务排队等待。

## 产品目标

1. 通过 MediaCrawler 开源项目实现多平台真实采集（当前支持小红书、抖音、知乎）。
2. 保持采集失败可控：失败写入采集任务，不影响后端服务，支持失败类型分类和重试。
3. 让业务用户能在前端看到真实采集源、采集状态、帖子、评论、线索和失败原因。
4. 线索管理支持完整状态流转：新线索 → 已跟进 → 有意向 → 无效 / 已转化，支持线索转 CRM 客户。
5. 今日报告面向客户可读，包含扫描概况、A级线索详情、典型证据、建议话术、同行发现、明日建议，支持 Markdown 导出。
6. 同行账号发现池支持审核通过后加入监控源。
7. 轻 CRM 跟进台支持线索转客户、手动录入客户、跟进记录、跟进时间提醒（7 种客户状态）。
8. 采集时间范围过滤，确保只入库近期有效数据。
9. 评分规则可视化管理，支持实时测试评分效果。
10. 仪表板全局统计概览，今日/昨日数据对比，CRM 跟进提醒。

## 范围边界

### 本阶段做

1. `keyword` / `competitor_account` / `manual_post` / `hot_post_rule` 监控源均使用 `config.collector_type = "media_crawler"`。
2. MediaCrawler 支持小红书、抖音、知乎三个平台的关键词搜索、指定帖子、创作者主页采集。
3. 创建监控源时后端校验平台与 collector_type 兼容性，media_crawler 仅允许 xhs/douyin/zhihu。
4. 前端监控源页默认 collector_type 为 media_crawler，平台选项仅展示 xhs/douyin/zhihu，创建时提示依赖 MediaCrawler API 服务。
5. 采集需 MediaCrawler API 服务在线（默认 `http://127.0.0.1:8080`），或设置 `MEDIA_CRAWLER_HOME` 使用内嵌模式。
6. 帖子/评论去重（platform + post_id / comment_id 唯一约束），避免重复入库。
7. 评论为空允许采集成功，线索数可以为 0。
8. 错误信息脱敏，采集失败不暴露内部细节。
9. 帖子池、评论池、采集任务页支持核验采集结果。
10. 线索池支持完整状态流转（new/contacted/interested/invalid/converted）、备注、来源帖子双向导航、CSV 导出、线索转 CRM。
11. 今日获客报告包含：扫描概况、A级线索详情、典型证据、建议跟进话术、发现的同行账号、明日建议、CRM 统计，支持 Markdown 导出。
12. 同行账号发现池前端页面已挂载路由，支持查看、通过、忽略同行账号，通过后可加入监控源。
13. Smoke Test 覆盖完整链路验证。
14. 采集时间范围过滤：`config.time_range` 支持 `7d`/`15d`/`30d`/`90d`，设置后自动提升 `max_posts` 至 80，入库前按 `publish_time` 过滤帖子和评论。
15. 轻 CRM 跟进台：线索转客户（两种入口）、手动录入客户、客户状态管理（pending/contacted/interested/wechat_added/applied/converted/invalid）、跟进记录、跟进时间提醒（已逾期/今日跟进/明日跟进/本周跟进/暂无提醒）。
16. 定时采集调度：支持 Cron 表达式配置，APScheduler 自动触发采集任务。
17. 评分规则管理：可视化编辑线索评分规则，单条/批量测试评分效果，热重载。
18. 仪表板：全局统计概览，今日/昨日数据对比，CRM 跟进提醒统计，MediaCrawler 健康状态。
19. 采集任务队列管理：同一时间仅执行一个任务，支持队列状态查询。
20. 失败类型分类：8 种失败类型（media_crawler_unreachable / platform_not_supported / auth_required / captcha_or_risk_control / timeout / empty_result / parser_error / unknown），前端展示中文标签和处理建议。

### 本阶段不做

1. 不做 Mock 采集器路由（代码存在但 Factory 不路由，仅保留文件供参考）。
2. 不做 Playwright 采集器路由（代码存在但 Factory 不路由）。
3. 不做 ExternalApiCollector 路由（代码存在但 Factory 不路由）。
4. 不做 GenericWebCollector 路由（代码存在但 Factory 不路由）。
5. 不做登录态采集绕过。
6. 不做验证码处理。
7. 不做代理池、Cookie 池、账号池。
8. 不做指纹伪装、风控绕过、反爬绕过。
9. 不新增员工管理、自动发布、复杂权限或智能体编排。

## 前端导航结构

顶部导航栏 6 个菜单项：

| 菜单 | 路由 | 说明 |
|------|------|------|
| 工作台 | `/` | 仪表板：全局统计、CRM 提醒、MediaCrawler 健康状态 |
| 监控源 | `/collection` | 监控源管理 + 采集任务中心（双 Tab） |
| 线索池 | `/leads` | 线索管理（子路由含帖子池、评论池、评分规则） |
| CRM 跟进 | `/crm` | CRM 仪表板 + 客户列表 + 跟进记录 |

| 获客报告 | `/daily-reports` | 今日报告生成与展示 |

## 用户流程

1. 用户进入仪表板，查看全局统计概览和 CRM 跟进提醒。
2. 进入"监控源"页面，页面顶部提示"当前采集依赖 MediaCrawler API 服务"。
3. 创建关键词监控源：
   - `source_type`: `keyword`
   - `platform`: `xhs`（小红书）—— 平台选项仅展示 xhs/douyin/zhihu
   - `collector_type`: `media_crawler`（默认值，唯一选项）
   - `value`: `征信花了`
   - `time_range`: `7d`（可选，设置后仅入库 7 天内的内容，采集量自动提升）
   - `schedule_cron`: `0 */2 * * *`（可选，设置后自动定时采集）
4. 点击"立即采集"，任务加入采集队列，进入采集任务中心确认任务状态。
5. 在采集任务列表查看任务详情：
   - 列表展示：任务 ID、平台、来源类型、来源值、状态、帖子/评论/线索/同行数量、失败类型、开始/结束时间
   - 点击"详情"打开任务详情弹窗，分区展示基础信息、采集配置、采集结果统计
   - 失败任务：弹窗显示错误详情、原因分析、修复建议，支持一键"重试采集"
   - 运行中/排队中任务：弹窗显示 loading spinner 和当前进度
   - 成功任务：弹窗提供快捷入口（查看帖子、查看评论、查看线索、生成日报）
6. 采集成功后，进入帖子池、评论池，展示采集到的真实数据。
7. 进入线索池，展示线索识别结果（A/B/C/D 等级）：
   - 每条线索展示：来源平台、来源帖子、评论内容、命中证据、判断理由、跟进话术、跟进状态、备注
   - 可修改线索状态：新线索 → 已跟进 → 有意向 → 无效 / 已转化
   - 可添加备注
   - 点击来源帖子可跳转
   - 可直接将线索转为 CRM 客户
8. 点击"导出 CSV"，下载线索数据（包含备注列）。
9. 将线索转为 CRM 客户，进入轻 CRM 跟进台：
   - CRM 仪表板展示统计概览和跟进提醒（已逾期/今日/明日/本周）
   - 客户列表支持按状态（7 种）、来源、跟进提醒筛选
   - 可添加跟进记录（电话/微信/短信/上门/其他），设置下次跟进时间
   - 客户状态流转：待跟进 → 已联系 → 有意向 → 已加微信 → 已申请 → 已转化 / 无效
10. 进入今日报告，选择平台（全平台/小红书/抖音/知乎），点击"生成今日报告"：
    - **今日扫描概况**：监控源数量、帖子数量、评论数量、线索数量、A级线索数量，含线索等级分布条形图
    - **A级线索 Top 10**：用户名、评论内容、需求类型、判断理由、建议话术，按评分排序
    - **典型需求证据**：命中关键词标签、金额信息、高频需求柱状图、高频关键词标签云
    - **同行账号发现**：账号名、平台、发现原因、建议是否监控
    - **明日采集建议**：推荐关键词、推荐同行方向、推荐内容选题、跟进提示
    - **CRM 统计**：今日新增客户、待跟进、已逾期、已转化
    - **合规提醒**：避免承诺下款、避免夸大利率、避免诱导负债、建议使用咨询/评估类话术
    - 点击"复制摘要"可一键复制纯文本版报告
    - 点击"导出 Markdown"可下载报告文件
    - 空数据状态友好提示（如"今日暂无A级线索"）
11. 进入"同行发现"页面，查看自动发现的同行账号：
    - 支持通过/忽略操作
    - 通过后可加入监控源
12. 进入"评分规则"页面，查看和编辑线索评分规则：
    - 可视化编辑评分维度、权重、关键词模式
    - 单条/批量测试评分效果
    - 热重载规则
13. 回到监控源管理，创建指定帖子监控源：
    - `source_type`: `manual_post`
    - `platform`: `xhs`
    - `value`: 一个小红书笔记链接
14. 点击"立即采集"。
15. 如果成功，进入帖子池查看原链接，进入评论池按帖子 ID 核验评论，再进入线索池查看是否识别出线索。
16. 如果失败，进入采集任务中心展示任务详情弹窗，查看错误信息、原因分析和修复建议，点击"重试采集"重新执行。

## 验收标准

1. MediaCrawler 服务在线时，关键词搜索采集链路可跑通（小红书/抖音/知乎）。
2. 指定帖子链接采集可跑通。
3. 采集失败时后端不崩溃，采集任务有清晰脱敏的 `error_message` 和失败类型分类。
4. 前端构建通过，监控源页能创建 media_crawler 采集源，平台选项仅展示 xhs/douyin/zhihu。
5. 后端校验平台与 collector_type 兼容性，不支持的组合返回 400。
6. 帖子池能打开原链接，评论池能按帖子 ID 核验评论。
7. 线索池支持完整状态流转、备注、来源帖子双向导航、CSV 导出、线索转 CRM。
8. 今日报告可生成和展示，包含 A级线索详情、典型证据、建议话术、同行发现、明日建议、CRM 统计，支持 Markdown 导出。
9. 同行账号审核页面可访问，支持通过/忽略操作。
10. Smoke Test 全链路 PASS。
11. 时间范围过滤生效：设置 `time_range=7d` 后，仅入库 7 天内的帖子和评论，`max_posts` 自动提升至 80。
12. CRM 跟进台可访问，支持线索转客户（两种入口）、手动录入、7 种客户状态、跟进记录、跟进时间提醒。
13. 定时采集调度可配置和运行。
14. 评分规则可编辑、单条/批量测试、热重载。
15. 仪表板可访问，展示全局统计、CRM 提醒、MediaCrawler 健康状态。
16. 采集任务队列正常工作，同一时间仅执行一个任务。
17. 失败类型分类正确，前端展示中文标签和处理建议。

## 后续路线

1. 恢复 MockCollector 到 Factory 路由，保证无 MediaCrawler 服务时演示可跑。
2. 扩展 MediaCrawler 支持更多平台（快手、B站、微博、贴吧）。
3. 增加 ExternalApiCollector，接入合规第三方采集服务。
4. 增加 GenericWeb selector 配置能力。
5. 线索自动分配和跟进提醒增强。
6. 多租户和基础权限。
7. 日报 PDF 导出。
8. 线索详情弹窗展示完整证据链。
9. 线索批量操作（批量标记状态、批量导出）。
10. CRM 客户详情页完善（来源帖子、来源线索关联展示）。
11. CRM 跟进提醒通知增强（站内通知、邮件提醒）。
