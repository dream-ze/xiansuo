# PRD：智获客 · 助贷线索雷达

## 作用

记录智获客的产品目标、采集边界、验收标准和后续路线。本文档以当前代码能力为准：系统包含三大模块——线索雷达（基于 MediaCrawler 多平台采集）、小红书运营（账号管理、内容创作、AI 改写、自动发布）和智能工作流（RAG 知识库、LangGraph 工作流、ReAct 智能体、合规审核）。

## 当前阶段

当前阶段是"线索雷达 + 小红书运营 + 智能工作流一体化平台"，面向客户可试用、可交付、愿意付费。

### 线索雷达核心链路

监控源管理 → 定时采集调度 → 采集任务队列 → MediaCrawler 采集 → 时间范围过滤 → 帖子池 → 评论池 → 线索识别与去重 → 线索池 → 线索转 CRM → 轻 CRM 跟进台 → 今日获客报告 → CSV/Markdown 导出 → 同行账号发现池 → 评分规则管理 → 仪表板

### 小红书运营核心链路

账号矩阵管理（QR/手机/Cookie 登录） → 笔记发现与收藏 → 关键词组管理 → AI 内容改写/生成 → 图片工坊/视频工坊 → 草稿工坊 → 发布中心 → 自动运营任务 → 数据洞察

### 智能工作流核心链路

知识库索引（笔记/帖子 → ChromaDB 向量化） → RAG 语义检索 → LangGraph 工作流编排（线索评分 / 话术生成 / 内容发布审核） → 合规规则检查 → 风险门控 → 人工审批队列 → ReAct 智能体多轮对话

## 产品目标

### 线索雷达

1. 通过 MediaCrawler 开源项目实现多平台真实采集（当前支持小红书、抖音、知乎）。
2. 保持采集失败可控：失败写入采集任务，不影响后端服务，支持失败类型分类和重试。
3. 让业务用户能在前端看到真实采集源、采集状态、帖子、评论、线索和失败原因。
4. 线索管理支持完整状态流转：新线索 → 已跟进 → 有意向 → 无效 / 已转化，支持线索转 CRM 客户。
5. 今日报告面向客户可读，包含扫描概况、A级线索详情、典型证据、建议话术、同行发现、明日建议，支持 Markdown 导出。
6. 同行账号发现池支持审核通过后加入监控源。
7. 轻 CRM 跟进台支持线索转客户、手动录入客户、跟进记录、跟进时间提醒（7 种客户状态）。
8. 采集时间范围过滤，确保只入库近期有效数据。
9. 评分规则可视化管理，支持实时测试评分效果。
10. 仪表板全局统计概览，今日/昨日数据对比，CRM 跟进提醒。

### 小红书运营

11. 用户认证系统：注册/登录/JWT 双 Token 机制，密码 PBKDF2 加密存储。
12. 小红书账号矩阵管理：PC 端 / 创作者端双类型账号，支持二维码登录、手机验证码登录、Cookie 导入三种方式，Cookie 加密存储，PC Cookie 自动同步创作者端。
13. 笔记发现与收藏：基于账号批量采集小红书笔记，保存笔记详情、评论、素材（图片/视频）。
14. AI 内容创作：笔记改写、笔记生成、标题生成、标签生成、文本润色、封面图生成、图片生成、图片/视频描述。
15. 图片工坊：图片上传、AI 合成封面图（标题+正文+配色）、图片缩放裁剪。
16. 视频工坊：视频上传、ffmpeg 截取封面帧、AI 视频内容描述。
17. 草稿工坊：AI 草稿管理、编辑、一键发送至发布中心。
18. 发布中心：小红书创作者端发布（即时/定时），支持话题、位置、隐私设置，素材上传，发布状态跟踪。
19. 自动运营：关键词驱动的自动发布任务，支持手动/定时/周期调度。
20. 数据洞察：运营总览、热门内容、热门话题、评论分析、竞品对标。
21. 标签系统：笔记标签管理，标签颜色自定义，笔记-标签多对多关联。
22. 通知系统：站内通知，按级别分类（info/warning/error/success），未读计数。
23. 任务中心：统一任务管理，任务状态/进度/耗时/子任务，调度器状态查询。
24. 模型配置：AI 模型管理（文本/图片），API Key 加密存储，默认模型切换。
25. 文件管理：媒体文件上传/下载，图片合成/缩放，文件权限校验（按用户隔离）。

### 智能工作流

26. RAG 知识库：基于 LlamaIndex + ChromaDB 的向量知识库，支持笔记/帖子索引、语义检索、智能问答，每用户独立 Collection。
27. LangGraph 工作流引擎：支持线索评分（规则预筛 + AI 识别 + 持久化）、话术生成（RAG 检索 + AI 生成 + 合规检查 + 风险门控）、内容发布审核（质量评估 + 合规检查 + 风险门控）三种工作流。
28. 合规规则管理：支持平台规则、行业规范、内部策略三类规则，4 级严重程度（low/medium/high/critical），默认 9 条规则一键初始化。
29. 风险门控与审批队列：工作流合规检查发现风险时自动暂停，创建审批记录，支持人工审核通过/拒绝，审核时可修改内容。
30. ReAct 智能体：基于 LangGraph 的多轮对话智能体，支持 5 种工具（知识库检索、合规审核、话术生成、线索评分、质量评估），对话上下文持久化，支持多轮对话续接。
31. 工作流运行记录：完整的运行状态追踪（pending/running/paused/completed/failed/cancelled），节点执行日志（耗时、Token 消耗、费用估算），支持暂停恢复。

## 范围边界

### 本阶段做

#### 线索雷达

1. `keyword` / `competitor_account` / `manual_post` / `hot_post_rule` 监控源均使用 `config.collector_type = "media_crawler"`。
2. MediaCrawler 支持小红书、抖音、知乎三个平台的关键词搜索、指定帖子、创作者主页采集。
3. 创建监控源时后端校验平台与 collector_type 兼容性，media_crawler 仅允许 xhs/douyin/zhihu。
4. 前端监控源页默认 collector_type 为 media_crawler，平台选项仅展示 xhs/douyin/zhihu，创建时提示依赖 MediaCrawler API 服务。
5. 采集需 MediaCrawler API 服务在线（默认 `http://127.0.0.1:8080`），或设置 `MEDIA_CRAWLER_HOME` 使用内嵌模式。
6. 帖子/评论去重（platform + post_id / comment_id 唯一约束），避免重复入库。
7. 评论为空允许采集成功，线索数可以为 0。
8. 错误信息脱敏，采集失败不暴露内部细节。
9. 帖子池、评论池、采集任务页支持核验采集结果。
10. 线索池支持完整状态流转（new/contacted/interested/invalid/converted）、备注、来源帖子双向导航、CSV 导出、线索转 CRM。
11. 今日获客报告包含：扫描概况、A级线索详情、典型证据、建议跟进话术、发现的同行账号、明日建议、CRM 统计，支持 Markdown 导出。
12. 同行账号发现池前端页面已挂载路由，支持查看、通过、忽略同行账号，通过后可加入监控源。
13. Smoke Test 覆盖完整链路验证。
14. 采集时间范围过滤：`config.time_range` 支持 `7d`/`15d`/`30d`/`90d`，设置后自动提升 `max_posts` 至 80，入库前按 `publish_time` 过滤帖子和评论。
15. 轻 CRM 跟进台：线索转客户（两种入口）、手动录入客户、客户状态管理（pending/contacted/interested/wechat_added/applied/converted/invalid）、跟进记录、跟进时间提醒（已逾期/今日跟进/明日跟进/本周跟进/暂无提醒）。
16. 定时采集调度：支持 Cron 表达式配置，APScheduler 自动触发采集任务。
17. 评分规则管理：可视化编辑线索评分规则，单条/批量测试评分效果，热重载。
18. 仪表板：全局统计概览，今日/昨日数据对比，CRM 跟进提醒统计，MediaCrawler 健康状态。
19. 采集任务队列管理：同一时间仅执行一个任务，支持队列状态查询。
20. 失败类型分类：8 种失败类型，前端展示中文标签和处理建议。

#### 小红书运营

21. 用户认证：注册/登录，JWT access + refresh 双 Token，密码 PBKDF2_SHA256 加密。
22. 平台账号管理：小红书 PC 端 / 创作者端账号，支持 QR 码登录、手机验证码登录、Cookie 文本导入。
23. Cookie 安全：Cookie 使用 Fernet 对称加密存储，按版本管理，支持自动同步创作者端。
24. 笔记管理：基于平台账号批量保存小红书笔记，保存笔记详情、素材（图片/视频）、评论。
25. AI 内容创作：基于 OpenAI 兼容 API 的文本生成（改写/生成/标题/标签/润色）和图片生成（封面/图片/描述）。
26. 草稿系统：AI 生成的草稿管理，支持编辑、标签、发送至发布中心。
27. 发布工作流：草稿 → 发布任务 → 素材上传 → 创作者端发布，支持即时/定时发布。
28. 视频工坊：视频上传、ffmpeg 截取封面帧、AI 视频描述。
29. 图片工坊：图片上传、AI 合成封面图、图片缩放裁剪。
30. 自动运营：关键词驱动的自动发布任务，支持手动/定时/周期调度。
31. 数据洞察：运营总览、热门内容、热门话题、评论分析、竞品对标。
32. 标签系统：笔记标签 CRUD，标签颜色自定义，笔记-标签多对多关联。
33. 关键词组：分组管理采集关键词，支持多平台。
34. 通知系统：站内通知，按级别分类，未读计数，标记已读。
35. 任务中心：统一任务管理，任务状态/进度/耗时/子任务，调度器状态。
36. 模型配置：AI 模型管理（文本/图片），API Key 加密存储，默认模型切换。
37. 文件管理：媒体文件上传/下载，图片合成/缩放，文件权限校验（按用户 ID 前缀隔离）。
38. 监控快照：XHS 监控目标刷新时保存快照数据。
39. API 日志：记录关键 API 调用日志，含请求/响应/耗时。

#### 智能工作流

40. RAG 知识库：LlamaIndex + ChromaDB 向量存储，支持笔记/帖子批量索引、语义检索（similarity_top_k + rerank）、智能问答（tree_summarize/refine/compact），每用户独立 Collection。
41. 线索评分工作流：规则预筛（LeadScoringService）→ AI 线索识别（StructuredLLM）→ 线索持久化，LangGraph 图编排，支持规则和 AI 双重评分。
42. 话术生成工作流：RAG 检索（知识库参考素材）→ AI 话术生成（2-3 个风格候选）→ 合规检查 → 风险门控，高风险自动进入审批队列。
43. 内容发布审核工作流：AI 质量评估（相关性/完整性/可读性 0-1 评分）→ 合规检查 → 风险门控，高风险自动进入审批队列。
44. 合规规则管理：CRUD + 一键初始化默认规则（9 条：3 条平台规则 + 3 条行业规范 + 3 条内部策略），4 级严重程度。
45. 审批队列：工作流风险门控自动创建，支持通过/拒绝，通过时可修改内容，审批结果关联工作流恢复。
46. ReAct 智能体：LangGraph ReAct 图，5 种工具（knowledge_search / compliance_check / script_generate / lead_score / quality_eval），ConversationBufferMemory 多轮对话，对话记录持久化到 agent_conversations 表。
47. 工作流运行记录：WorkflowRun + WorkflowLog 双表记录，支持运行状态查询、节点日志查看、暂停恢复。
48. 工作流节点：rule_prescreen / ai_lead_identify / lead_persist / rag_retrieve / ai_script_generate / compliance_check / risk_gate / human_approval / ai_quality_eval 共 9 个可复用节点。

## 用户流程

### 线索雷达流程

1. 用户进入仪表板，查看全局统计概览和 CRM 跟进提醒。
2. 进入"采集中心"页面，页面顶部提示"当前采集依赖 MediaCrawler API 服务"。
3. 创建关键词监控源：
   - `source_type`: `keyword`
   - `platform`: `xhs`（小红书）—— 平台选项仅展示 xhs/douyin/zhihu
   - `collector_type`: `media_crawler`（默认值，唯一选项）
   - `value`: `征信花了`
   - `time_range`: `7d`（可选，设置后仅入库 7 天内的内容，采集量自动提升）
   - `schedule_cron`: `0 */2 * * *`（可选，设置后自动定时采集）
4. 点击"立即采集"，任务加入采集队列，进入采集任务中心确认任务状态。
5. 在采集任务列表查看任务详情：
   - 列表展示：任务 ID、平台、来源类型、来源值、状态、帖子/评论/线索/同行数量、失败类型、开始/结束时间
   - 点击"详情"打开任务详情弹窗，分区展示基础信息、采集配置、采集结果统计
   - 失败任务：弹窗显示错误详情、原因分析、修复建议，支持一键"重试采集"
   - 运行中/排队中任务：弹窗显示 loading spinner 和当前进度
   - 成功任务：弹窗提供快捷入口（查看帖子、查看评论、查看线索、生成日报）
6. 采集成功后，进入帖子池、评论池，展示采集到的真实数据。
7. 进入线索池，展示线索识别结果（A/B/C/D 等级）：
   - 每条线索展示：来源平台、来源帖子、评论内容、命中证据、判断理由、跟进话术、跟进状态、备注
   - 可修改线索状态：新线索 → 已跟进 → 有意向 → 无效 / 已转化
   - 可添加备注
   - 点击来源帖子可跳转
   - 可直接将线索转为 CRM 客户
8. 点击"导出 CSV"，下载线索数据（包含备注列）。
9. 将线索转为 CRM 客户，进入轻 CRM 跟进台：
   - CRM 仪表板展示统计概览和跟进提醒（已逾期/今日/明日/本周）
   - 客户列表支持按状态（7 种）、来源、跟进提醒筛选
   - 可添加跟进记录（电话/微信/短信/上门/其他），设置下次跟进时间
   - 客户状态流转：待跟进 → 已联系 → 有意向 → 已加微信 → 已申请 → 已转化 / 无效
10. 进入今日报告，选择平台（全平台/小红书/抖音/知乎），点击"生成今日报告"：
    - 今日扫描概况、A级线索 Top 10、典型需求证据、同行账号发现、明日采集建议、CRM 统计、合规提醒
    - 支持复制摘要、导出 Markdown
11. 进入"同行发现"页面，查看自动发现的同行账号，支持通过/忽略操作。
12. 进入"评分规则"页面，查看和编辑线索评分规则，支持单条/批量测试、热重载。

### 小红书运营流程

1. 用户注册/登录系统，获取 JWT Token。
2. 进入"账号矩阵"页面，添加小红书账号：
   - QR 码登录：生成二维码，手机扫码确认
   - 手机验证码登录：输入手机号 → 发送验证码 → 确认登录
   - Cookie 导入：粘贴 Cookie 文本，系统解析并加密存储
   - 可选同步创作者端：PC Cookie 自动换取创作者端 Cookie
3. 进入"笔记发现"页面，基于已登录账号搜索和浏览小红书笔记，收藏感兴趣的笔记。
4. 进入"关键词组"页面，创建和管理采集关键词分组。
5. 进入"草稿工坊"页面：
   - 基于收藏笔记 AI 改写生成草稿
   - 或输入主题 + 参考 + 指令 AI 生成新草稿
   - 编辑草稿标题、正文、标签
   - 生成 AI 封面图
6. 进入"图片工坊"页面，上传图片、AI 合成封面图、缩放裁剪图片。
7. 进入"视频工坊"页面，上传视频、截取封面帧、AI 描述视频内容。
8. 进入"发布中心"页面：
   - 从草稿发送至发布中心
   - 选择发布账号、发布模式（即时/定时）
   - 设置话题、位置、隐私选项
   - 上传素材（图片/视频）
   - 提交发布，跟踪发布状态
9. 进入"自动运营"页面，创建自动发布任务：
   - 配置关键词、AI 指令
   - 选择 PC/创作者端账号
   - 设置调度方式（手动/定时/周期）
10. 进入"数据洞察"页面，查看运营总览、热门内容、热门话题、评论分析。
11. 顶部通知铃铛查看站内通知，按级别分类展示。
12. 进入"任务中心"查看所有后台任务状态和调度器运行情况。
13. 进入"模型配置"管理 AI 模型（文本/图片），配置 API Key 和默认模型。

### 智能工作流流程

1. 进入"知识库"页面，管理知识条目：
   - 查看知识库统计（总数、按类型分布、ChromaDB 状态）
   - 索引笔记到知识库（选择笔记或一键索引全部）
   - 语义检索测试（输入查询文本，查看相关结果）
   - 知识问答测试（输入问题，获取 AI 基于知识库的回答）
2. 进入"合规规则"页面，管理合规审核规则：
   - 查看规则列表（按类别、严重程度筛选）
   - 一键初始化默认规则（9 条：平台规则 + 行业规范 + 内部策略）
   - 创建/编辑/删除自定义规则
3. 进入"AI 助手"页面，与智能体对话：
   - 输入问题（如"帮我生成一条针对急需5万周转客户的跟进话术"）
   - 智能体自动调用工具：先检索知识库参考素材，再生成话术，最后检查合规性
   - 查看工具调用历史和最终回答
   - 支持多轮对话续接（传入 thread_id）
4. 工作流自动触发场景：
   - 采集到新评论后，自动触发线索评分工作流（规则预筛 → AI 识别 → 持久化）
   - 线索需要跟进时，触发话术生成工作流（RAG 检索 → AI 生成 → 合规检查 → 风险门控）
   - 发布内容前，触发内容发布审核工作流（质量评估 → 合规检查 → 风险门控）
5. 进入"审批中心"页面，处理待审批内容：
   - 查看待审批列表（按风险等级、内容类型筛选）
   - 查看合规检查详情和风险原因
   - 通过审批（可修改内容后通过）或拒绝
6. 进入"工作流"页面，查看工作流运行记录：
   - 按类型（线索评分/话术生成/内容发布/智能体）和状态筛选
   - 查看运行详情和节点执行日志（耗时、Token 消耗、费用估算）
   - 恢复暂停的工作流
